MECHA OVERDRIVE — CIRCUIT ZERO 2.4.0
====================================

ÉTAT DE CETTE COPIE
- Les sources Godot locales sont en 2.4.0 et ont passé le parse moteur ainsi que
  les six tests smoke, locomotion, runtime, sécurité/mobile, garage et narration.
- L’export Web présent dans godot3d/ est le build 2.4.0 mono-thread synchronisé.
- `npm run qa` est vert : 115/115, 12/12, 21/21 et validation Godot statique.
- La QA Chrome a couvert le bureau 1258 × 622 et le mobile 844 × 390.
- GitHub Actions, la release publique v2.4.0 et l’alias Vercel ont été vérifiés.

LANCER LES SOURCES 2.4.0 AVEC GODOT
1. Ouvrir Godot 4.7.2.
2. Importer le projet situé dans le dossier godot/.
3. Lancer res://scenes/app.tscn.

WINDOWS — BUILD WEB 2.4.0
1. Double-cliquer sur LANCER_JEU.bat.
2. Le navigateur s’ouvre sur un port local disponible à partir de 8080.
3. Laisser la fenêtre du serveur ouverte pendant la partie.

MACOS / LINUX — BUILD WEB 2.4.0
1. Ouvrir un terminal dans ce dossier.
2. Exécuter : chmod +x LANCER_JEU.sh
3. Exécuter : ./LANCER_JEU.sh

NODE.JS
- npm start
- Puis ouvrir l’adresse affichée.
- Accès direct au build Web actuel : /godot3d/mecha-overdrive.html

POINTS FORTS 2.4.0
- Saison 03 « La Couronne Libre » de la Nexus Grand League : huit mondes,
  trois galaxies, dix pilotes, intro en trois chapitres et huit archives Codex.
- Garage 3D plein écran derrière le HUD avec aperçu immédiat et quatre membres
  d’équipe animés, désactivables par le réglage de mouvement réduit.
- 19 assets bitmap OpenAI originaux et manifestés.
- Huit pistes homologuées à 35 m minimum et grille professionnelle 2 × 4.
- Commandes clavier, manette et mobile multi-touch.
